# Security Policy

## Supported version

Security fixes target the latest commit on the default branch.

## Reporting

Do not open a public issue for a suspected vulnerability. Use the repository's private **Security → Advisories → Report a vulnerability** channel instead:

<https://github.com/happyzhangdy-max/xingxiaozhi-english-corner/security/advisories/new>

Include reproduction steps, affected versions, impact, and any suggested mitigation. Do not access data that does not belong to you or disrupt services while investigating.
