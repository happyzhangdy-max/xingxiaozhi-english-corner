# Contributing

Thanks for helping improve 行小之英语角.

## Before opening a change

- Use an issue for substantial new banks, data-source changes, or behavior changes.
- Keep entries practical, concise, and grounded in a real workplace or life scenario.
- Do not paste proprietary glossaries, paid-course material, personal data, or text with unclear reuse rights.
- Record every imported or adapted source and license in `docs/OPEN_DATA.md` and `THIRD_PARTY_NOTICES.md`.

## Development

```bash
npm install
npm run dev
npm run typecheck
npm run lint
npm test
```

Pull requests should explain the user-facing change, verification performed, and any data-license implications. Keep changes focused; avoid unrelated refactors.

By contributing project-authored learning content, you agree that it can be distributed under CC BY 4.0. Code contributions are distributed under MIT.
